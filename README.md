# 재고관리 시스템

설치 없이 브라우저에서 바로 쓰는 재고관리 웹 앱입니다. 데이터는 브라우저의 localStorage에 저장됩니다.

## 주요 기능

- **대시보드**: 등록 품목 수, 총 재고 수량, 재고 금액, 안전재고 미달·품절 품목 수, 최근 입출고 10건
- **품목 관리**: 등록·수정·삭제, 품목코드(SKU) 중복 방지, 분류·보관 위치·단위·단가·안전재고 관리
- **입고 / 출고 / 실사 조정**: 재고보다 많은 출고는 차단, 모든 변동을 이력으로 기록(잔량 포함)
- **검색·필터·정렬**: 품목코드·이름·분류·위치 검색, 분류별 필터, 부족 품목만 보기, 열 제목 클릭 정렬
- **입출고 이력**: 구분·기간·키워드 필터, CSV 내보내기
- **데이터**: 품목 CSV 내보내기/가져오기(엑셀 호환), JSON 전체 백업/복원, 예시 데이터

안전재고 이하인 품목은 노란색, 품절 품목은 빨간색으로 표시됩니다.

## 실행

`index.html`을 더블클릭해 브라우저로 바로 열면 됩니다. 로컬 웹 서버로 열어도 됩니다.

```bash
npm start          # http://localhost:8080
# 또는
python3 -m http.server 8080
```

GitHub Pages 등 정적 호스팅에 그대로 올려도 동작합니다.

## CSV 형식

```
sku,name,category,location,unit,quantity,minStock,price
OF-001,A4 복사용지,사무용품,A-1,박스,12,5,25000
```

- `sku`, `name`은 필수입니다.
- 이미 등록된 품목코드는 정보가 갱신되고, `quantity` 차이는 "조정" 이력으로 남습니다.
- 잘못된 행은 건너뛰고 행 번호와 사유를 알려 줍니다.

## 구조

```
index.html           화면
src/inventory.js     재고 로직 (순수 함수, UI와 분리)

src/style.css        스타일 (다크 모드 지원)
test/                로직 단위 테스트
```

```bash
npm test
```

## 참고

데이터는 사용 중인 브라우저에만 저장됩니다. 다른 기기와 공유되지 않고, 브라우저 데이터를 지우면 사라지므로 **데이터 → 백업 파일 저장**으로 주기적으로 백업하세요.
